# Design Context — fin.kirakon.com

## Design Context

### Users
Single user: Kiran (the owner). Personal finance tracking — not a SaaS product. Used daily, often alone, in a focused state. The user is technical, financially literate, and cares deeply about data quality. Context: private, attentive, high-trust.

### Brand Personality
**Sharp · Precise · Modern**

Less warm coffeehouse, more private Bloomberg terminal. The interface should feel like it was built by someone who cares about the numbers as much as the aesthetics. Like a well-maintained spreadsheet that became beautiful. Analytical confidence, not casual warmth.

### Aesthetic Direction
- **Theme**: Light mode. Coffee palette stays as the foundation (espresso nav, caramel accents) but pushed toward crispness — tighter spacing, stronger contrast, less softness.
- **Typography**: Replace the generic Segoe UI / system-ui stack with a purposeful pairing — a sharp, modern sans-serif that feels like a financial tool.
- **References**: Bloomberg Terminal aesthetics (data density, precision) married to Linear.app (clean, fast, sharp) — but with the warmth of the coffee palette keeping it from feeling cold.
- **Anti-references**: Avoid glassy/frosted effects, avoid generic card grids, avoid decorative gradients.

### Design Principles
1. **Data is the hero** — Never let chrome compete with numbers. Typography, spacing, and color all serve legibility of financial data.
2. **Every pixel earns its place** — No decoration without purpose. Shadows, borders, and accents exist to separate or emphasize, not to decorate.
3. **Precise rhythm** — Spacing uses a strict 4/8/12/16/24/32px scale. Randomness in spacing destroys trust.
4. **States are never missing** — Every interactive element has hover, focus, active, disabled, loading, and error states. Incomplete interaction models feel broken.
5. **Sharp at rest, alive in motion** — Static states are crisp and still. Motion is purposeful — transitions confirm state changes without announcing themselves.
